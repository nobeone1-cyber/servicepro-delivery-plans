# ServicePro Repair Tracking — Pilot

เว็บแอปติดตามการรับสินค้า ส่งซ่อม ใบเสนอราคา QC ซ่อมซ้ำ เปลี่ยนสินค้า และส่งคืนลูกค้า รุ่น Pilot พร้อมฐานข้อมูล SQLite กลางสำหรับใช้งานร่วมกันในเครือข่าย LAN

## เปิดใช้งาน

ต้องใช้ Node.js 22.5 ขึ้นไป เนื่องจากระบบใช้ SQLite ที่มากับ Node.js

```powershell
npm start
```

หรือเปิด `start-servicepro.ps1` จาก PowerShell แล้วเข้าใช้งานผ่าน:

- เครื่อง Server: `http://127.0.0.1:4173`
- เครื่องอื่นใน LAN: `http://<IP-เครื่อง-Server>:4173`

ข้อมูลกลางเก็บใน `data/servicepro.sqlite` ซึ่งจะสร้างให้อัตโนมัติเมื่อเปิด Server ครั้งแรก ตัว Browser ยังเก็บสำเนาชั่วคราวไว้เพื่อให้ทำงานต่อได้เมื่อการเชื่อมต่อสะดุด และจะซิงก์กลับเมื่อ Server พร้อม

## ความสามารถ

- สร้าง Job หนึ่งใบพร้อมสินค้าหลายรายการ
- Workflow แยกแต่ละสินค้า
- ใบเสนอราคาและการอนุมัติก่อนซ่อม
- ส่งช่างภายในหรือ Vendor พร้อม Repair Round
- QC ผ่าน/ไม่ผ่าน และส่งซ่อมซ้ำ
- ซ่อมไม่ได้ ไม่พบอาการ คืนโดยไม่ซ่อม และเปลี่ยน S/N
- ส่งคืนและปิดรายการ
- Timeline ผู้ทำรายการและเวลา
- Customer, Product, Vendor, Employee Master
- Dashboard, Search, Filter และรายงาน
- Export/Import JSON สำหรับสำรองและย้ายข้อมูล
- Print view

## ข้อมูลจำลอง

หน้า Dashboard มีแผง “เครื่องมือจำลองระบบ”:

- **สร้างข้อมูลจำลอง** เพิ่มชุดงานใหม่ 10 Jobs / 19 Items ต่อท้ายข้อมูลเดิม ครอบคลุมโรงพยาบาล ทีม Service, Admin, ช่างภายใน, Vendor ภายนอก และสถานะทั้งหมด
- Master Data ที่มีรหัสหรือชื่อเดิมจะไม่ถูกสร้างซ้ำ แต่ Job, เลขงาน และ S/N ในแต่ละชุดจะไม่ซ้ำกัน
- **ล้างข้อมูลทั้งหมด** ลบทั้งงานและ Master Data หลังพิมพ์คำยืนยัน `ล้างข้อมูลทั้งหมด`
- ควรกด “ส่งออกข้อมูล” ก่อนล้างหากต้องการเก็บสำรอง

## ข้อจำกัดสำคัญ

รุ่นนี้ซิงก์ฐานข้อมูลกลางแบบ revision และตรวจข้อมูลใหม่ทุก 3 วินาที เหมาะกับการทดลองใช้ภายในทีมขนาดเล็ก หากแก้ Job เดียวกันพร้อมกัน ระบบจะเลือกข้อมูล Job ที่มีเวลาอัปเดตใหม่กว่า ชื่อผู้ทำรายการยังมาจาก dropdown จึงไม่ใช่หลักฐานยืนยันตัวตน ก่อนใช้ข้อมูลจริงควรเพิ่ม Authentication, Role Security, HTTPS และ File Storage แยกสำหรับรูปภาพ

## สำรองข้อมูล

กด “ส่งออกข้อมูล” เป็นประจำ ระบบจะดาวน์โหลดไฟล์ JSON ซึ่งนำกลับเข้าระบบด้วยปุ่ม “นำเข้าข้อมูล” ได้ และควรสำรองไฟล์ `data/servicepro.sqlite` ขณะที่หยุด Server แล้วเป็นประจำ
