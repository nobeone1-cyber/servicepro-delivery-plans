# ServicePro Repair Tracking — Pilot

เว็บแอปติดตามการรับสินค้า ส่งซ่อม ใบเสนอราคา QC ซ่อมซ้ำ เปลี่ยนสินค้า และส่งคืนลูกค้า รุ่น Pilot แบบไม่มี Login

## เปิดใช้งาน

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม ข้อมูลจะเก็บใน Local Storage ของ Browser เครื่องที่ใช้งาน

## ความสามารถ

- สร้าง Job หนึ่งใบพร้อมสินค้าหลายรายการ
- Workflow แยกแต่ละสินค้า
- ใบเสนอราคาและการอนุมัติก่อนซ่อม
- ส่งช่างภายในหรือ Vendor พร้อม Repair Round
- QC ผ่าน/ไม่ผ่าน และส่งซ่อมซ้ำ
- ซ่อมไม่ได้ ไม่พบอาการ คืนโดยไม่ซ่อม และเปลี่ยน S/N
- ส่งคืนและปิดรายการ
- Timeline ผู้ทำรายการและเวลา
- Customer, Product, Vendor, Employee Master
- Dashboard, Search, Filter และรายงาน
- Export/Import JSON สำหรับสำรองและย้ายข้อมูล
- Print view

## ข้อมูลจำลอง

หน้า Dashboard มีแผง “เครื่องมือจำลองระบบ”:

- **สร้างข้อมูลจำลอง** เพิ่มชุดงานใหม่ 10 Jobs / 19 Items ต่อท้ายข้อมูลเดิม ครอบคลุมโรงพยาบาล ทีม Service, Admin, ช่างภายใน, Vendor ภายนอก และสถานะทั้งหมด
- Master Data ที่มีรหัสหรือชื่อเดิมจะไม่ถูกสร้างซ้ำ แต่ Job, เลขงาน และ S/N ในแต่ละชุดจะไม่ซ้ำกัน
- **ล้างข้อมูลทั้งหมด** ลบทั้งงานและ Master Data หลังพิมพ์คำยืนยัน `ล้างข้อมูลทั้งหมด`
- ควรกด “ส่งออกข้อมูล” ก่อนล้างหากต้องการเก็บสำรอง

## ข้อจำกัดสำคัญ

รุ่นนี้เป็น Pilot แบบ local-first ข้อมูลยังไม่ sync ข้ามเครื่อง และชื่อผู้ทำรายการมาจาก dropdown จึงไม่ใช่หลักฐานยืนยันตัวตน ก่อนใช้หลายคนหรือข้อมูลจริงควรเชื่อม Firebase/ฐานข้อมูลกลาง เพิ่ม Authentication, Role Security และ File Storage

## สำรองข้อมูล

กด “ส่งออกข้อมูล” เป็นประจำ ระบบจะดาวน์โหลดไฟล์ JSON ซึ่งนำกลับเข้าระบบด้วยปุ่ม “นำเข้าข้อมูล” ได้
